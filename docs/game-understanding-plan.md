# Game Understanding Module Plan

## Position

Game Understanding is a core module, not the whole product.

Input:
- screenshot
- gameplay video
- reference images

Output:
- Game Blueprint
- Asset Map
- UI Map
- Gameplay Analysis
- Required Production Tasks

## Architecture

Vision Analyzer
-> Gameplay Analyzer
-> Asset Detector
-> Blueprint Generator
-> Existing Asset Pipeline
-> Exporters

## Goal

Allow a user to provide a game reference and generate a structured plan that can call the other modules of AI Game Factory.
