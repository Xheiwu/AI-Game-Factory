# Auto Sprite v2 Pipeline

## Goal
Convert AI generated character concepts into engine-ready animated assets.

## Flow
Prompt -> Character Design -> Animation Plan -> Frames -> Sprite Sheet -> Metadata -> Export

## Animation Profiles
- RPG Character: idle, walk, attack, skill, hurt, death
- Roguelike Character: move, shoot, dash, hit, die

## Output
- sprite sheet
- animation json
- engine export package
