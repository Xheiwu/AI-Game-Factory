# AI Game Factory Modules

## Core modules

- Game Understanding
  - screenshot/video analysis
  - gameplay inference
  - asset mapping
  - blueprint generation

- Asset Factory
  - sprite
  - pixel
  - tileset
  - UI
  - VFX
  - audio

- Style Memory
  - project visual rules
  - references
  - consistency checks

- Export Layer
  - Unity
  - Godot
  - Web
  - TapMaker

Each module is independent and connected through Asset Package and Game Blueprint formats.
